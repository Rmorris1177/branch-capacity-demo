# Branch capacity demo

A fictional-only, self-contained browser demo for development projects,
supplier comparison, sample reservations, capacity, and action tracking.
No passcode or installation is required. Changes are saved in your browser.
Branch AI provides clearly labeled demo insights; no live AI key is included.

## Enable the website

In this repository, open Settings > Pages. Under Build and deployment:

- Source: Deploy from a branch
- Branch: main
- Folder: / (root)
- Save

GitHub displays the live website link after deployment completes.

This repository contains only the fictional demo, this README, and .nojekyll.
It contains no desktop source, database, private Git history, or credentials.
